# 🌦️ Weather App

A modern and responsive Weather Application developed using HTML, CSS, and JavaScript. The application fetches real-time weather data from the OpenWeather API and provides users with accurate weather information for any city worldwide.

---

## 🚀 Features

- 🌍 Select city from dropdown
- 🌡 Real-time temperature
- 💧 Humidity
- 💨 Wind Speed
- 🤗 Feels Like Temperature
- 🌅 Sunrise & Sunset Time
- 🌤 Weather Icons
- 📍 Current Location Weather
- 🔄 Celsius / Fahrenheit Toggle
- 🌙 Dark Mode
- 📅 5-Day Weather Forecast
- 📱 Responsive Design

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- OpenWeather API

---

## ▶️ How to Run

1. Clone the repository.
2. Open the project in VS Code.
3. Add your OpenWeather API key in `script.js`.
4. Open `index.html` using Live Server.
5. Select a city and view the weather.
